# 家有数

供家庭使用的收入与资产管理网页，使用手机或电脑浏览器访问，可部署到群晖Docker。

当前版本：**0.16.0-preview**。镜像仓库：[hpnzss/jiayoushu](https://hub.docker.com/r/hpnzss/jiayoushu)。

## 功能与流程

- 五个页面：家庭总览、记录与更新、收入统计、账户与资产、设置与备份，支持电脑和手机布局、主屏幕安装及深浅主题。
- 首次创建一位管理员，在设置管理成员和密码。通过恢复码或本机工具找回管理员访问权限。
- 建立资金账户，填写初始余额/市值；收入按成员、来源和到账账户记录，转账/换汇不计为收入。公积金单独补录或定期入账。
- 定期核对实际余额与持仓估值，多币种自动引用最新可用参考汇率；保存后固定汇率。缺少数据不按0折算。历史收入可早于账户纳入日，不重复增加期初余额。
- 总览展示家庭资产、资产变化及期间收入。收入提供成员与家庭的月年曲线、跨年比较、构成、明细、CSV导出和历史导入。资产提供历史曲线、类型/币种分布及账户备注。图表可独立开关数字，日期筛选直接展开。
- 收入按发生日期、资产按盘点日期随时更新；可以只更新部分账户，无需开期、关账或集中填报。旧关账摘要随备份保留，但不再锁定历史记录。
- 本软件不提供支出录入、统计或推算；不将收入与资产变化之差视作消费、结余或投资收益。旧版支出仅做备份兼容保留，不参与当前计算和展示。
- 收入、账户、资产历史及导入记录可在各自页面修改/删除，从回收站恢复。SQLite本地保存，完整备份及校验恢复。

安装步骤见[INSTALL.md](INSTALL.md)，版本变化见[CHANGELOG.md](CHANGELOG.md)。升级须先备份并保留data目录。

## 开发与发布

普通分支或PR运行测试。版本标签或main上的手动发布通过检查后，更新Docker Hub的固定版本、提交标签及preview。先在隔离的虚拟账本中本地预览和测试，再发布镜像；预览资料不会进入公开源码。

AI自然语言/截图识别及自动股票报价尚未接入。手机尺寸预览不替代真实iPhone原生选择器、主屏幕安装和会话行为验收。外汇参考值并非银行实时成交价。
