# 家有数

供家庭使用的收支与资产管理网页，使用手机或电脑浏览器访问，可部署到群晖 Docker。

当前版本：**0.9.0-preview**（开发预览）。镜像仓库：[hpnzss/jiayoushu](https://hub.docker.com/r/hpnzss/jiayoushu)。`preview` 跟随通过发布检查的 main 分支；每次构建还提供 commit 标签，本版提供 `0.9.0-preview` 标签。发布状态见 [GitHub Actions](https://github.com/hpnzss/jiayoushu/actions)。

## 功能

- 家庭总览、月度填报、收支统计、账户与资产、设置与备份五个页面，支持深浅色主题和手机布局。
- 首次创建一位管理员，再在设置中管理家庭成员；成员可修改自己的密码，管理员可重置成员密码。恢复码或本机工具可找回管理员访问权限。
- 现金、银行存款、平台余额、股票、理财、基金、加密货币、贵金属和其他类型统一管理。支持自定义名称和分类，汇丰银行区分中国与香港。
- 收入区分成员、来源和到账账户；记录内部转账与换汇，不重复计算家庭收入。
- 每位成员每月填写一个支出净总额，家庭自动合计，不再次扣减账户余额。
- 月度盘点自动引用最新可用外汇参考值，显示来源及日期，保存后固定；缺少汇率不会按0或1折算。补录旧月份按最新参考值估值时会明确标注。其他历史流水需要对应日期的参考汇率。
- 月中可核对余额与估值、预览截至当日的结果；月底条件齐全后正式关账，锁定历史。管理员可倒序重开。
- 收入按成员和家庭合计展示逐月、逐年曲线；资产随记录点变化，并说明每个指标的意义。
- CSV或Excel表格粘贴导入历史收入及家庭总资产，支持检查预览、去重与更正，不改变当前银行卡余额。
- SQLite 本地保存、完整账本备份、每日自动备份与经过校验的恢复。

## 修改、删除与图表

管理员在月度填报的“已录记录 · 修改与删除”编辑或删除记录，在设置的回收站恢复。删除收入或转账后由剩余记录重算，后续实际盘点仍有效；月支出和历史汇总不加减银行卡余额。已有正式关账须先重开。账户归档须先核对余额为0；删除账户会同时移走关联流水，先显示影响并自动备份。恢复不覆盖现有记录。

收入到账账户按本人及共同账户筛选，当前浏览器按登录身份记住常用账户、来源。成员可标记男、女或不指定用于配色，家庭合计为粗线。月/年收入和资产图支持缩放、滑块和拖动，圆点可查看金额；可切换时间快捷范围及不同年份逐月比较。移除成员后不再显示其个人图表，但历史收入保留在家庭合计中。

## 0.9图表与iPhone主屏幕

“家庭收入构成”用环形图展示所选期间家庭收入的成员金额与比例，不受收入明细单成员筛选影响；已移除成员的历史收入合并为匿名“历史其他收入”。

时间快捷项为近1月、年初至今、近半年、近1/2/3/5年和有史以来；近1月从上月同日开始（不足取该月末日）到今天，包含首尾。原“年度”快捷项移除，曲线的按月/按年粒度仍保留。跨年比较以不同颜色表示年份、线型表示成员、粗实线表示家庭。

全部收入和资产曲线提供纵轴自动适配、放大/缩小、从0开始及手动金额上下限。坐标显示真实金额，范围外记录不删除，数据表保留完整金额。

iPhone通过Safari添加到主屏幕时，登录页及所有子页面共用名称“家有数”、钱包logo、manifest和根路径启动入口。没有添加离线账本缓存，访问数据仍需连接NAS。旧主屏幕入口建议移除后重新添加，以重新读取名称和图标；这只移除快捷入口，不删除服务器账本。已有账号首次使用新版本不会重复自动弹指引；“稍后”和已完成状态保存在服务器，可在设置中手动继续/重看。

安装元数据参照[Apple配置说明](https://developer.apple.com/library/archive/documentation/AppleApplications/Reference/SafariWebContent/ConfiguringWebApplications/ConfiguringWebApplications.html)及[WebKit主屏幕Web应用说明](https://webkit.org/blog/13878/)。本机已验证元数据、公开图标、390px布局和暂停后的页面切换/重载；真实iPhone安装及系统缓存行为还需在设备上确认。

## 历史导入

收支统计顶部进入“导入历史收入”，账户与资产顶部进入“导入历史总资产”。设置与备份中也有统一入口。导入和更正需要管理员。

通用收入表头为 `期间,成员,收入金额,备注`，每行是一位成员该期间的收入合计，不限两个人。成员先在设置中添加，按称呼匹配；重名时使用页面显示的成员编号。

期间可填写日期（`2018-01-15`）、月份（`2018-01`）、年份（`2018`），或自选起止日期（`2018-01-01~2018-03-31`）。只接受已结束的期间，支持2000年起的日期。金额按人民币填写；不知道的记录省略，明确没有收入填0。

保留两人月收入快捷表，表头为 `月份,成员一收入,成员二收入,备注`，两列分别选择对应成员；空白不视为0。家庭总资产表头为 `日期,家庭总资产,备注`，不要求银行卡明细。支持CSV和从Excel复制的区域，暂不直接读取xlsx，每批最多2000行、900KB。

同一成员的汇总期间不能重叠，也不能与已录逐笔收入重复统计。年度合计不会伪造各月收入，跨年合计不会自动拆成年份；图表会提示无法放入该粒度的记录。自选统计区间只有覆盖完整汇总期间时才计入该条收入。历史家庭总额仅作为独立资产点，不虚构账户分布，不替代月度账户核对。

## 部署

详见 [安装、升级与备份](INSTALL.md)。示例 compose 默认使用 Docker Hub 的 `preview` 镜像；需要固定本版可改为 `hpnzss/jiayoushu:0.9.0-preview`。

需要从源码运行时，安装 Node.js 24 后运行：

```sh
node server.cjs
```

浏览器打开 `http://127.0.0.1:4318/`，首次创建管理员，数据默认保存在 `data/family.sqlite`。无需安装npm依赖。从源码构建镜像可运行 `docker build -t jiayoushu:local .`。

开发预览可运行 `node preview.cjs`，打开 `http://127.0.0.1:4321/preview`。该入口仅限本机，使用独立 `.preview-data` 目录及明确标注的虚拟汇率，不能公开托管真实账本。

## 版本与检查

更新内容见 [CHANGELOG](CHANGELOG.md)。GitHub Actions 先运行账户、收支、权限、汇率、关账、图表、历史导入和备份测试，再构建并运行隔离容器健康检查，最后推送 Docker Hub。当前镜像为 `linux/amd64`，适用于 DS423+；未发布ARM镜像。

所有测试使用临时账本和虚拟数据。仓库不包含真实家庭账本、口令、恢复码、备份或私人环境配置。公开源码不代表公开部署者的家庭数据。AI自然语言、截图识别和实时股票行情尚未接入。

银行名称参考 [金融监管总局2025年6月30日法人机构名单](https://www.nfra.gov.cn/chinese/docfile/2025/86c58b1ad810422c8fa6c6d0107f1626.pdf)，并补充常见港澳银行；名单不是实时服务目录。新版界面参考 [MoviePilot Frontend v3.1.4](https://github.com/jxxghp/MoviePilot-Frontend/tree/v3.1.4) 的主题与响应式设计思路，独立实现。外汇参考值来自 [欧洲央行](https://www.ecb.europa.eu/stats/policy_and_exchange_rates/euro_reference_exchange_rates/html/index.en.html)，并非银行实时成交价。
