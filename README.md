# 家有数

供家庭使用的收支与资产管理网页，使用浏览器访问，可部署到群晖 Docker。

**当前状态：开发预览版，尚未发布 Docker Hub 镜像。** 这是源代码的首次整理，不能当作已完成的稳定版本。当前尚未决定开源许可证。

## 已有功能

- 五个页面：家庭总览、月度填报、收支统计、账户与资产、设置与备份。
- 首次创建一位管理员；管理员在设置添加成员，成员可修改自己的密码，管理员可重置成员密码。恢复码或本机工具可找回管理员访问权限。
- 统一管理现金、银行存款、网络平台余额、股票、理财、基金、加密货币、贵金属和其他类型；支持自定义类型、银行/平台、收入来源，保存后可复用。
- 收入按成员、来源及到账账户记录；账户转账不重复计算收入。
- 每人每月一个支出净总额，家庭自动合计；支出统计不再次扣减账户余额。
- 多币种参考汇率，支持手动确认历史汇率；股票等资产可录总市值或数量×单价，不提供实时股票行情。
- 月中可按日期保存实际余额；整月结束、月末余额及支出填齐后手动关账，管理员可倒序重开。
- SQLite 本地持久化、账本导出、每日自动备份和经过校验的恢复。

## 本机运行

需要 Node.js 24，无须安装 npm 依赖。

node server.cjs

浏览器打开 http://127.0.0.1:4318/ ，首次创建管理员。默认账本在 data/family.sqlite。

需要虚拟数据预览时运行 node preview.cjs，打开 http://127.0.0.1:4321/preview 。该入口仅限本机，使用独立 .preview-data 目录，不能用来公开托管真实账本。

## 验证

测试使用临时账本和合成口令，不包含家庭真实数据。在 Node.js 24 下分别运行：

- node verify-unified.cjs：账户类型、银行名单、收入、分人支出、多币种、导入去重和备份校验。
- node verify-http.cjs：登录、成员权限、关账及恢复接口。
- node verify-periods.cjs：月度核对、关账、重开与历史保护。
- node verify-backup.cjs：完整恢复、恢复前安全副本与并发覆盖保护。
- node verify-deployment.cjs：域名端口、HTTPS Cookie 与跨站提交检查。
